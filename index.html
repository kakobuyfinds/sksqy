What to check before ordering

  1. Save the original seller URL and the exact size and color. Check whether your selected agent accepts that link and ships to your destination.
  2. For shoes, compare the sizing chart with your foot measurements and confirm whether each measurement refers to foot or insole length. For clothing, compare garment measurements with a piece you own.
  3. If warehouse quality-control photos are available, check the size label, color and visible damage. Ask about unclear measurements while the return window is still open.
Does every CAFANS listing offer HooBuy?

Agent options vary by listing. Open the product page to see the available platforms and check the original seller link if you want to use a specific agent.

Why can shipping quotes differ for the same item?

Carriers can use actual or dimensional weight. Compare the packed parcel dimensions, billable weight and included fees for the same destination.
